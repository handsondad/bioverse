# 生物奇遇记 · 题库

每一题都是一篇「小念 × 爸爸」文章的种子。每个主题下有两张表：

- **已写**（✅）：已经写成文章的题（以 `npm run story:todo` 为准，标题以 curriculum 的 `question` 为准）。🔭 = 同时是 3D 实验台那节课。新题别和它们重复，可以用 `prerequisites` 指向它们。
- **候选**：还没写的题。写之前照 sources.md 重新查证，表里的说法只是方向，不能直接当事实抄进文章。写完把这一行挪进「已写」表。

新题按同样的列加进对应主题的「候选」表。选题标准：

- **从生活出发**：小念在家里、厨房、公园、动物园、学校生物课上真会碰到的一幕。
- **破一个误区**：每题至少瞄准一个真实存在的常见误区（「植物不呼吸」「演化是为了」「细菌都是坏的」「抗生素能杀病毒」……）。
- **对得上课标**：入门 ≈ 小学高年级 / 初中七八年级，进阶 ≈ 初中拔高 / 高一必修，综合 ≈ 高中（必修、选择性必修）。
- **能动手**：每题配一张能拖滑块的互动图（已有的写 `sims.ts` 里的名字，新的写「新：名字（滑块）」）。
- **讲机制，不讲感觉**：「身体上的感觉」归身体奇遇记，见文末「别和身体奇遇记撞题」。
- **查证去处**：写文章时数字和说法要去这些地方核实，写进文章的「参考来源」。OpenStax **不读不用**。
