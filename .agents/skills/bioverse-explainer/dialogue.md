# 写问答

文章写在 `src/learning/stories/<slug>.ts`，导出一个 `Story`（类型见同目录 `types.ts`），登记在 `stories/index.ts`（CRLF 换行）。`npm run story:new -- <slug>` 会把这两步做好。写完跑 `npm run story:check -- <slug>`，再跑 `npm run voice -- <slug>` 配音。

**对话会被读出来**：小念和爸爸的每一句都是配音稿，写成嘴上说得出的话。化学式、算式放进 `eq`（不读），句子里说中文名和中文单位：「二氧化碳」「大约 37 摄氏度」「每分钟 70 下」。非写符号不可时，`src/learning/voice.ts` 的 `speakable()` 和 `BIO_SYMBOLS` 会把常见的念成中文：`CO₂` → 二氧化碳、`O₂` → 氧气、`Na⁺` → 钠离子、`Dd` → 大D小d、`XY` → X和Y、`ATP` → 能量分子、`DNA` → D N A、`mRNA` → 信使 R N A、`pH` → 酸碱度、`℃`、`μm`、`mV`、`%`、`37–40` 这类单位和范围。`story:check` 对念不顺的英文字母串会给 ⚠️，缺的念法补进 `BIO_SYMBOLS`（改了念法，受影响的文章要重跑 `voice`）。

## 字段

| 字段 | 写什么 |
|---|---|
| `slug` | 和 `curriculum.ts` 里的课一致 |
| `title` | 小念口吻的问题，必须带「？」，和 curriculum 的 `question` 一字不差：「馒头本来不甜，嚼着嚼着怎么变甜了？」 |
| `trigger` | 小念刚遇到的那件事，一句话、具体到场景：「在动物园喂长颈鹿吃树叶时，旁边有人说……，小念半信半疑地问爸爸。」 |
| `dialogue` | 5–8 轮 `{ nian, dad, eq?, figure?, show? }` |
| `tip` | 给大人：安全须知、数字的口径、和教材写法的差别、这个误区从哪来、可以在家一起做的小观察；至少 20 字 |
| `sources` | 参考来源，至少 2 条，见 sources.md |
| `film` | 讲解动画，每篇都要有，见 film.md |

每轮里：
- `eq`：这一轮的式子或过程，单独排一行（`淀粉 → 麦芽糖`、`葡萄糖 + 氧气 → 二氧化碳 + 水 + 能量`、`Dd × Dd → 1 DD : 2 Dd : 1 dd`）。入门的题尽量不放，进阶最多一两条，综合可以多一些。
- `figure`：爸爸边说边指的一张图，见 figures.md。
- `show`：`{ kind: 'lab', step, label }` 记下这一轮对应 3D 实验第 `step` 段（从 0 数，`label` 要包含那一段的名字）；或 `{ kind: 'steps', frames }` 一排 2–4 格的小图解（emoji + ≤8 字），讲「先……再……最后……」的过程最合适。

## 检查器会拦的

- 5–8 轮；标题带「？」；`trigger` 一句话（≥8 字）。
- 除最后一轮外，小念每句都带「？」。
- 从第 2 轮起，小念的问题要用上爸爸上一句里的一个有意义的两字词（「细胞」「淀粉」「变异」；「什么」「这个」不算）。检查器取相邻两个汉字，其中一个是「的了吗呢吧呀啊哦嘛是我你他她它们这那就也都还又在有和么什怎为个一不没会要说想看能可以得很太好真再」这类虚字就不算；最稳的是让小念原样复述爸爸刚说的一个名词：「既然使劲伸长不会改写 DNA，那……」。
- 最后一轮小念以「我懂了」或「我明白了」开头。
- 爸爸每句 20–180 字；`tip` 至少 20 字；`sources` 至少 2 条。

## 写好的标准（检查器管不到的）

**小念**：孩子的口气，短句，带情绪：「哇，我的舌头好麻！」。追问顺着爸爸刚说的新词往下挖，不跳题：爸爸说了「酶」，小念就问「酶是活的小虫子吗？」。小念可以先说出那个常见的错误想法（「是不是祖先天天伸脖子，越拉越长？」），让爸爸接着说破——这是破误区最自然的写法。

**爸爸**：
- 第一句就给答案，再解释。
- 一个比方只讲一件事，用孩子见过的东西：工厂流水线（细胞器分工）、钥匙和锁（酶和受体）、快递打包（囊泡）、充电宝（ATP）、菜谱（DNA）、门卫（细胞膜）、接力赛（神经冲动）。比方有漏洞就说一句「别全信这个比方」。
- 比方说完说真名，只说一次：「……这就叫渗透作用。」后面就直接用。
- 数字要真实、可查（写进 `sources`）；图里和动画里出现的数字只能是爸爸说过的。不确定就直说「科学家还在研究」或「大约」。
- 误区点名说破：「很多人以为……，其实……」，再给一个孩子能自己验证的证据（一个小观察、一个日常现象）。
- 不堆术语：「原生质层」「同源染色体」这类词，入门题不说；进阶、综合题要用就先打比方。
- 学段对齐：入门题讲现象和定性的道理；进阶题讲结构、过程和简单的比例；综合题可以讲分子机制和遗传图解，但先讲道理再给式子。

**生物题特别要注意的**：
- **别说「为了」**：演化没有目的。不说「长颈鹿为了吃高处的叶子把脖子变长」，说「脖子长的更容易活下来、留下更多后代」。植物也不「想」「故意」，可以拟人打比方，但要回到真机制。
- **结构和功能对上**：讲一个结构，就讲它让生物能做什么（鳃丝多→面积大→换气多）。
- **物质和能量有去处**：讲吃进去、吸进去、长出来的东西，最后去了哪里（脂肪大部分变成二氧化碳呼出去）。
- **尊重生命**：观察动物不打扰、不伤害；不教采摘、品尝野生动植物；家里的小实验用厨房里安全的材料。
- **健康题不当医生**：疫苗、抗生素、发烧、血糖讲机制和好习惯，具体用药写进 `tip`：「请遵医嘱」。

**追问链的常见顺序**（不必每次全用）：
1. 看到了什么（现象）
2. 细胞 / 分子 / 器官里一步步在发生什么
3. 为什么非得这样，对生物有什么好处，不这样会怎样
4. 常见误区或特例
5. 生活里能用来做什么 / 我能做什么
6. 小念总结，爸爸肯定并给一个好习惯或一个能回家看的小观察

## 例子（`evolution-giraffe.ts`）

```ts
{
  nian: '爸爸，长颈鹿的脖子有两米多长，真的是它们祖先天天使劲伸脖子、越拉越长才遗传下来的吗？',
  dad: '好多人听过这个说法，但其实是错的哦！你想想，一个人天天举哑铃练出大肌肉，生下来的小宝宝不会天生满身肌肉对吧？后天用劲拉长并不会改写细胞里的 DNA，所以没法直接遗传给下一代！',
  figure: { kind: 'sim', sim: 'giraffeSelect', caption: '向右拖动经过的世代，看看在高树叶环境里长脖子比例怎样代代上升。' },
},
{
  nian: '既然使劲伸长不会改写 DNA，那长颈鹿怎么最后全长出了这么长的脖子？',
  dad: '达尔文找到了真正的答案——自然选择！……',
  show: { kind: 'steps', frames: [{ icon: '🎲', label: '天生有长短变异' }, { icon: '🌿', label: '旱季高叶更易活' }, { icon: '🦒', label: '代代筛选成群变长' }] },
},
```

第 1 轮小念说出了误区，爸爸当场说破并给了一个孩子能想明白的反例（练出的肌肉不遗传）；第 2 轮的「伸长」「改写」接的是爸爸上一句的原话，这就是追问链。

## 草稿怎么改

`story:new` 预填的是自动装配的问答（3D 实验课用课件的一问一答，生活问题用 `curriculum.ts` 里的 hook 和 takeaway），口气不对。改写时：
- 删掉「教材」「本实验」「实验台上」「图 3-2」这类老师口吻，换成小念生活里的场景；
- 并掉重复的轮次，控制在 5–8 轮；
- 3D 实验课保留 `show.lab` 的段号（和课件对得上），删掉用不上的；
- 把注释掉的 `// figure:` 换成真的图，把 `sources` 填上；
- 草稿里的 `film` 只是占位，照 film.md 给每一轮配戏。

改了已有文章的对话：只要动了字，就重跑 `npm run voice -- <slug>`；如果增删了轮次，动画场次的 `turn` 也要跟着挪。
